# React Course App - Nhóm 4

## Hướng dẫn cài đặt & chạy ứng dụng
1. Clone dự án: `git clone <link-github>`
2. Cài đặt thư viện: `npm install`
3. Chạy ứng dụng: `npm run dev`

## Phân công làm nhánh (Branch):
- `feature/p2-component`: Trung làm CourseList, CourseCard
- `feature/p3-state`: Phúc làm SearchBar, Filter
- `feature/p4-api`: Minh kết nối API & useEffect
